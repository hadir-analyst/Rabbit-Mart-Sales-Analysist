#  Rabbit Mart — Retail Sales Analysis

##  Project Overview

Rabbit Mart is a retail sales analysis portfolio project developed using Microsoft Power BI. The project focuses on data cleaning, data transformation, data modeling, and interactive dashboard development to analyze sales performance, profitability, and discount impact.

**Project Branding:** Rabbit Mart is a fictional brand name created specifically for this portfolio project to present the analysis in a business-oriented context. It does not represent the original owner of the dataset.

**Dataset Disclaimer:** This project uses a publicly available sample retail sales dataset obtained from Kaggle. The dataset is used for educational and portfolio purposes.

## Project Objectives

- Analyze overall sales and profitability.
- Identify profitable and loss-making transactions.
- Evaluate the impact of discounts on profit margins.
- Explore sales performance across product categories, regions, and time periods.
- Build a structured data model to support efficient analysis.
- Transform raw data into meaningful business insights through interactive visualizations.

##  Data Cleaning & Preparation

Data cleaning and transformation were performed using Power Query in Power BI.

Key tasks included:
- Removed unnecessary columns to simplify the dataset.
- Identified and removed duplicate records.
- Addressed data quality issues.
- Transformed and prepared the data for analysis.
- Organized the data into a structured model for reporting and visualization.

## Data Modeling

Designed a **Star Schema** to organize the data into fact and dimension tables.

This structure improves data organization, simplifies relationships between tables, and supports efficient analytical queries and reporting in Power BI.

## 📊Dashboard & Analysis

Developed an interactive Power BI dashboard to explore key business metrics and uncover insights into retail sales performance.

The analysis covers:
- Sales and profit performance.
- Profitability across products and categories.
- Discount impact on profit margins.
- Sales trends across regions and time periods.
- Identification of profitable and loss-making transactions.

##  Key Business Insights

- **Net Profit:** Approximately $286K.
- **Profitability Analysis:** Identified profitable and loss-making transactions.
- **Discount Impact:** Discounts above 20% were associated with negative profit margins in the analyzed data.
- **Sales Trends:** Explored sales patterns across different product categories, regions, and time periods.

*Note: These findings reflect the results of the analysis and should be interpreted within the context of the sample dataset.*
